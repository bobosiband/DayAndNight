# Bongani Sibanda — DevSoc Portfolio

A personal portfolio website with a living sky theme for the UNSW DevSoc Training Program.

## Features
- Digital clock with timezone selector
- Animated sky that transitions through dawn, day, sunset, and night
- Sun and moon arcs across the sky
- Star field at night
- Live weather via Open-Meteo with no API key
- Rain, storm, fog, and cloud effects
- Profile page with courses and projects

## Running Locally
Open `index.html` in a browser, or serve the folder with a local server:

```bash
npx serve .
```

## APIs Used
- Open-Meteo for weather data
- Browser Geolocation API for location
- Intl.DateTimeFormat for timezone-aware time
